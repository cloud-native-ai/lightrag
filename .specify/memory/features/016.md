## Overview

LightRAG is an active open-source project with multiple contributors, but lacks a formal contributor guide, changelog, and standardized PR templates. These artifacts would streamline onboarding, ensure consistent contribution quality, and improve release communication.

## Latest Review

Initial draft — gap identified during DFX analysis (DFM: Design for Maintainability).

## Key Changes

1. Create CONTRIBUTING.md with setup instructions, coding standards, and PR process
2. Create CHANGELOG.md following Keep a Changelog format
3. Add PR template (`.github/PULL_REQUEST_TEMPLATE.md`) with constitution compliance checklist
4. Add issue templates for bugs, features, and questions
5. Automate changelog generation from conventional commits

## Implementation Notes

- CONTRIBUTING.md should reference `make dev` and setup wizard
- PR template must include constitution compliance per Governance section
- Changelog categories: Added, Changed, Deprecated, Removed, Fixed, Security
- Consider `release-please` or `commitlint` for automation
- Issue templates in `.github/ISSUE_TEMPLATE/`

## Future Evolution Suggestions

- Automated release notes generation from CHANGELOG
- Contributor recognition and leaderboard
- Code of conduct adoption
