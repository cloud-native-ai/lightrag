# Feature Detail: Containerization & Deployment

**Feature ID**: 009
**Name**: Containerization & Deployment
**Description**: Docker images (full, lite, postgres), Docker Compose configurations, CI/CD pipelines for publishing to Docker Hub and PyPI.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG provides multiple Docker image variants for different deployment scenarios, along with Docker Compose configurations for multi-service orchestration. CI/CD pipelines automate image publishing to Docker Hub, package publishing to PyPI, and code quality checks.

## Latest Review

Three Dockerfile variants (full, lite, postgres) with multi-platform builds. Docker Compose for full stack with bundled services. CI workflows for Docker publishing, PyPI publishing, linting, and testing.

## Key Changes

1. Three Docker image variants: full (all backends), lite (minimal), postgres (PG-focused)
2. Docker Compose for multi-service orchestration with bundled services
3. CI/CD: docker-publish, docker-build-manual, docker-build-lite, pypi-publish workflows
4. Multi-platform build support (amd64, arm64)
5. Docker build scripts for custom builds and flattening

## Implementation Notes

- `Dockerfile` is the full variant; `Dockerfile.lite` and `Dockerfile.postgres` for alternatives
- `docker-compose.yml` for standard deployment; `docker-compose.podman.yml` for Podman
- `docker-build.sh` and `docker-build-push.sh` for local builds
- CI workflows in `.github/workflows/` use GitHub Actions
- Docker Hub images: `hkuDS/lightrag`

## Future Evolution Suggestions

- Helm chart for Kubernetes deployment
- Docker Compose profiles for dev/staging/prod
- Automated image vulnerability scanning in CI
