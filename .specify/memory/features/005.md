# Feature Detail: Text Chunking Strategies

**Feature ID**: 005
**Name**: Text Chunking Strategies
**Description**: Multiple selectable text chunking strategies: Fixed-size, Recursive, Vector-based Semantic, and Paragraph Semantic chunking.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG offers four configurable chunking strategies for splitting documents before ingestion. Each strategy serves different document types and use cases: Fixed-size for uniform splitting, Recursive for natural boundaries, Vector-based for semantic coherence, and Paragraph Semantic for document-structure-aware chunking.

## Latest Review

All four chunking strategies operational. Paragraph Semantic chunking leverages document structure (headings, sections) for context-aware splits. Vector-based chunking uses embedding similarity to determine chunk boundaries.

## Key Changes

1. Four chunking strategies: Fix, Recursive, Vector, Paragraph
2. Paragraph Semantic chunking with document structure awareness
3. Token-size-aware chunking with tiktoken integration
4. Configurable chunk size and overlap parameters per strategy
5. Chunk schema (`chunk_schema.py`) for standardized chunk representation

## Implementation Notes

- `lightrag/chunker/` contains strategy implementations
- `recursive_character.py` uses langchain-text-splitters
- `semantic_vector.py` uses langchain-experimental SemanticChunker
- `paragraph_semantic.py` respects document heading hierarchy
- Chunk size measured in tokens via tiktoken

## Future Evolution Suggestions

- Adaptive chunking that auto-selects strategy based on document type
- Chunk overlap optimization based on content density
- Custom chunking strategy plugin support
