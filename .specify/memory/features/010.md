# Feature Detail: Evaluation & Tracing

**Feature ID**: 010
**Name**: Evaluation & Tracing
**Description**: RAGAS integration for RAG quality evaluation, Langfuse integration for LLM observability and tracing, and offline retrieval quality checks.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG integrates RAGAS for evaluating retrieval and generation quality (context precision, recall, faithfulness) and Langfuse for tracing LLM calls in production. An offline retrieval check tool validates retrieval quality against oracle datasets.

## Latest Review

RAGAS evaluation pipeline operational with sample datasets. Langfuse tracing for LLM observability. Offline retrieval check tool for quality validation.

## Key Changes

1. RAGAS integration for evaluation metrics (context precision, recall, faithfulness, relevancy)
2. Langfuse integration for LLM call tracing and observability
3. Offline retrieval quality check tool (`offline_retrieval_check.py`)
4. Sample evaluation datasets and oracle files
5. Evaluation CLI with `eval_rag_quality.py`

## Implementation Notes

- Evaluation dependencies in `[evaluation]` extra: `ragas`, `datasets`
- Observability dependencies in `[observability]` extra: `langfuse`
- `lightrag/evaluation/` contains evaluation scripts
- Sample data in `lightrag/evaluation/sample_documents/`
