# Feature Detail: Document Ingestion & Parsing

**Feature ID**: 001
**Name**: Document Ingestion & Parsing
**Description**: Multi-format document parsing and ingestion pipeline supporting PDF, DOCX, PPTX, XLSX, Markdown, HTML, images, and more.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG's document ingestion pipeline accepts diverse file formats and converts them into structured text ready for chunking and knowledge graph extraction. The parser subsystem supports native parsers (Markdown, HTML tables), third-party integrators (MinerU, Docling), and format-specific handlers (DOCX, PDF, PPTX, XLSX). A plugin registry allows external parsers to be registered dynamically.

## Latest Review

Comprehensive parser subsystem with multi-format support, external parser integration, and a debug CLI for parser troubleshooting. Sidecar format enables enriched document processing with metadata.

## Key Changes

1. Multi-format parser architecture with native and external backends
2. Plugin registry for dynamic parser registration and routing
3. Sidecar format for enriched document processing with metadata extraction
4. Parser debug CLI for troubleshooting parser pipelines
5. Third-party parser integration (MinerU, Docling) for multimodal content

## Implementation Notes

- Parsers are registered via `lightrag.parser.registry` and dispatched through `native_dispatch.py`
- External parsers require separate service deployment (MinerU/Docling)
- MIME type detection and content validation before processing
- Parser routing uses content-type and format heuristics

## Future Evolution Suggestions

- Streaming parser for large documents
- Incremental parsing for append-only document updates
- Parser performance benchmarking suite
