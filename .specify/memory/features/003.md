# Feature Detail: RAG Query & Retrieval

**Feature ID**: 003
**Name**: RAG Query & Retrieval
**Description**: Multiple query modes (local, global, hybrid, naive) with reranking, citation support, and context precision metrics.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG provides multiple retrieval strategies for querying the knowledge graph: local (neighborhood-focused), global (community-summary-based), hybrid (combined), and naive (vector-only). A reranker post-processes results for improved relevance. Results include citations for source traceability and retrieved contexts for evaluation metrics.

## Latest Review

Stable query pipeline with all four modes operational. Reranker integration improves mixed-query performance. Citation support enables source attribution. Context precision metrics supported via RAGAS integration.

## Key Changes

1. Four query modes: local, global, hybrid, naive with configurable parameters
2. Reranker integration for post-retrieval relevance scoring
3. Citation functionality for source attribution and traceability
4. Retrieved contexts returned alongside query results for evaluation
5. Role-specific LLM configuration for query processing

## Implementation Notes

- Query modes are implemented in `lightrag/operate.py`
- Reranker is pluggable via `lightrag/rerank.py`
- Citations embedded in response generation
- Context precision metrics require RAGAS evaluation mode

## Future Evolution Suggestions

- Query result caching for repeated queries
- Multi-hop reasoning across graph paths
- Query planning and decomposition for complex questions
