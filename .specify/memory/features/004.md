# Feature Detail: Multimodal Document Processing

**Feature ID**: 004
**Name**: Multimodal Document Processing
**Description**: RAG-Anything integration for processing images, tables, equations, and multimodal content within documents via MinerU and Docling services.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

Extends LightRAG's document processing to handle multimodal content: images, tables, mathematical equations, and other non-text elements. Integrates RAG-Anything for all-in-one multimodal RAG, with MinerU and Docling as external parsing services for high-fidelity extraction.

## Latest Review

Merged RAG-Anything into LightRAG core. Multimodal content parsing via MinerU/Docling services operational. VLM (Vision Language Model) role for image description generation.

## Key Changes

1. RAG-Anything integration merged into LightRAG core
2. MinerU service integration for high-fidelity document parsing
3. Docling service integration for document layout understanding
4. Multimodal context extraction (`multimodal_context.py`)
5. VLM role in LLM configuration for image description

## Implementation Notes

- Multimodal processing requires external MinerU or Docling services
- VLM role configured separately from text LLM roles
- `prompt_multimodal.py` contains multimodal-specific prompts
- Image content is described and indexed alongside text for retrieval

## Future Evolution Suggestions

- Native multimodal embedding without external services
- Video and audio content processing
- Multimodal query (image-based search)
