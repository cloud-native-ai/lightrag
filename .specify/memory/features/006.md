# Feature Detail: REST API Server

**Feature ID**: 006
**Name**: REST API Server
**Description**: FastAPI-based REST API server with document upload, query, graph management endpoints, JWT authentication, and WebUI frontend.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG ships with a production-ready FastAPI REST server that exposes document ingestion, querying, and knowledge graph management through HTTP endpoints. Includes JWT-based authentication, file upload handling, CORS configuration, and a built-in WebUI dashboard for interactive exploration.

## Latest Review

Stable API server with document routes, query routes, graph routes, and Ollama API proxy. JWT authentication with bcrypt password hashing. Gunicorn production runner available. WebUI built with Bun and served as static assets.

## Key Changes

1. FastAPI server with document upload, query, and graph management endpoints
2. JWT-based authentication with token refresh and password hashing
3. WebUI dashboard for interactive knowledge graph exploration
4. Gunicorn production runner with configurable workers
5. CLI entry points: `lightrag-server`, `lightrag-gunicorn`, `lightrag-hash-password`

## Implementation Notes

- `lightrag/api/lightrag_server.py` is the main server entry point
- Routers split by domain: `document_routes.py`, `query_routes.py`, `graph_routes.py`
- `ollama_api.py` proxies Ollama-compatible API for drop-in replacement
- Frontend built from `lightrag_webui/` using Bun, served as static assets
- API prefix support via `--api-prefix` and FastAPI `root_path`

## Future Evolution Suggestions

- API versioning strategy for backward compatibility
- Rate limiting and request throttling
- WebSocket support for streaming responses
- OpenAPI client SDK generation
