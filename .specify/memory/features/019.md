# Feature Detail: Kubernetes Deployment Support

**Feature ID**: 019
**Name**: Kubernetes Deployment Support
**Description**: Helm chart for Kubernetes deployment, with configurable scaling, health probes, and external storage backend integration.
**Status**: Draft
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG currently supports Docker Compose for orchestration but lacks Kubernetes-native deployment artifacts. A Helm chart would enable production-grade deployment on Kubernetes with proper health probes, resource limits, configurable scaling, and integration with external storage backends.

## Latest Review

Initial draft — gap identified during DFX analysis (DFD: Design for Deployment).

## Key Changes

1. Create Helm chart with Deployment, Service, ConfigMap, and Secret templates
2. Configure liveness and readiness probes for the API server
3. Support external storage backend configuration (PostgreSQL, Neo4j, etc.)
4. Add HorizontalPodAutoscaler support for API server scaling
5. Document K8s deployment in docs/ with example values files

## Implementation Notes

- Helm chart in `charts/lightrag/` directory
- Health check endpoint required (see Feature 018)
- Separate charts vs. umbrella chart for bundled services
- Consider init containers for storage backend readiness
- Resource limits should be documented with recommended values

## Future Evolution Suggestions

- K8s Operator for automated KG lifecycle management
- Service mesh (Istio/Linkerd) integration
- Multi-site deployment support via K8s federation
