# Feature Detail: Dependency Security Scanning

**Feature ID**: 014
**Name**: Dependency Security Scanning
**Description**: Automated vulnerability scanning of Python dependencies, SBOM generation, and security advisory monitoring in CI.
**Status**: Draft
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG has a rich dependency tree across core, API, storage, and LLM extras. There is currently no automated dependency vulnerability scanning. Adding this would protect users from known CVEs in transitive dependencies and provide supply chain transparency via SBOM generation.

## Latest Review

Initial draft — gap identified during DFX analysis (DFSec: Design for Security).

## Key Changes

1. Integrate `pip-audit` or `safety` for dependency vulnerability scanning
2. Add SBOM generation (CycloneDX or SPDX) to release workflow
3. Configure Dependabot or Renovate for automated dependency updates
4. Add security scanning step to CI pipeline
5. Document vulnerability disclosure and response process

## Implementation Notes

- `pip-audit` works with pip/uv; `safety` has a commercial tier
- SBOM can be generated with `pip-audit --require-hashes`
- Dependabot config in `.github/dependabot.yml`
- Should scan all extras, not just core dependencies
- False positive handling policy needed

## Future Evolution Suggestions

- Container image vulnerability scanning (Trivy/Grype)
- License compliance checking
- Signed releases and artifact attestation
