# Feature Detail: CLI Administration Tools

**Feature ID**: 012
**Name**: CLI Administration Tools
**Description**: Command-line tools for password hashing, cache management, vector DB rebuild, LLM cache migration, and knowledge graph visualization.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG provides a suite of CLI tools for administrative tasks: password hashing for API authentication, LLM query cache cleanup, vector database rebuild, LLM cache migration between formats, and a knowledge graph visualizer.

## Latest Review

Five CLI tools operational: `lightrag-hash-password`, `lightrag-download-cache`, `lightrag-clean-llmqc`, `lightrag-rebuild-vdb`, and the visualizer toolkit. Each tool is independently runnable via `pip install` entry points.

## Key Changes

1. Password hashing tool (`lightrag-hash-password`) for API auth setup
2. LLM query cache cleanup (`lightrag-clean-llmqc`)
3. Vector database rebuild (`lightrag-rebuild-vdb`)
4. LLM cache migration tool (`migrate_llm_cache.py`)
5. Knowledge graph visualizer (`lightrag_visualizer/`)

## Implementation Notes

- CLI entry points defined in `pyproject.toml` under `[project.scripts]`
- Tools located in `lightrag/tools/`
- Each tool has its own README with usage instructions
- Visualizer is a sub-package with its own dependencies
- Cache download tool (`download_cache.py`) supports offline mode

## Future Evolution Suggestions

- Unified CLI with subcommands (e.g., `lightrag admin <subcommand>`)
- Interactive mode for cache inspection
- Health check and diagnostics tool
