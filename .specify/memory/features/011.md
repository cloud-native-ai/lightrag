# Feature Detail: Code Quality & Linting

**Feature ID**: 011
**Name**: Code Quality & Linting
**Description**: Ruff-based linting and formatting, pre-commit hooks, pytest test framework with async support, and CI quality gates.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

LightRAG enforces code quality through Ruff for linting and formatting, pre-commit hooks for automated checks, and pytest for testing with async support. CI workflows validate linting and tests on every PR.

## Latest Review

Ruff configured with py310 target. Pytest with asyncio auto mode. Pre-commit hooks for ruff and basic checks. CI linting workflow and test workflow operational.

## Key Changes

1. Ruff linting and formatting with py310 target
2. Pre-commit hooks for automated quality checks
3. Pytest with asyncio auto mode for async test support
4. CI linting workflow (`.github/workflows/linting.yaml`)
5. CI test workflow (`.github/workflows/tests.yml`)

## Implementation Notes

- Ruff config in `pyproject.toml` under `[tool.ruff]`
- Pytest config in `pyproject.toml` under `[tool.pytest.ini_options]`
- Test dependencies in `[project.optional-dependencies].pytest`
- Tests organized by subsystem: `tests/api/`, `tests/kg/`, `tests/llm/`, etc.
- `conftest.py` provides shared fixtures

## Future Evolution Suggestions

- Test coverage reporting in CI
- Mutation testing for critical paths
- Type checking with mypy in CI
