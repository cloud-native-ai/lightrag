# Feature Detail: Interactive Setup Wizard

**Feature ID**: 008
**Name**: Interactive Setup Wizard
**Description**: Guided setup wizard for configuring LLM providers, embedding, reranking, storage backends, and server security via interactive prompts.
**Status**: Implemented
**Created**: 2026-06-23
**Last Updated**: 2026-06-23

## Overview

The setup wizard (`scripts/setup/setup.sh`) provides an interactive, step-by-step configuration experience for LightRAG. Users configure LLM backends, embedding models, rerankers, storage backends, and server settings through guided prompts. The wizard generates `.env` files and Docker Compose configurations for bundled services.

## Latest Review

Full setup wizard with base, storage, and server configuration phases. Supports validation, backup, security audit, and rewrite modes. Docker Compose generation for bundled service images.

## Key Changes

1. Three-phase setup: base (LLM/embedding/reranker), storage (backends), server (port/security/SSL)
2. `.env` generation with validation and security audit
3. Docker Compose generation for bundled services
4. Backup and rewrite modes for safe reconfiguration
5. Makefile targets for all setup phases

## Implementation Notes

- `scripts/setup/setup.sh` is the main entry point
- Compose templates in `scripts/setup/templates/*.yml`
- `make env-base`, `make env-storage`, `make env-server` shortcuts
- Security audit checks for exposed secrets and weak configurations
- Supports `SETUP_OPTS` for debug and non-interactive modes

## Future Evolution Suggestions

- Non-interactive/headless mode with config file input
- Configuration profiles for multiple environments
- Migration helper for upgrading from older config formats
